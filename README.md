# MainiTech Strategic Solutions — Official Website

This repository contains the complete, production-ready website code for **MainiTech Strategic Solutions** led by Nakul Maini. It is specifically designed to be hosted completely free on **GitHub Pages**.

## Key Features
- **Modern, Trust-Focused Aesthetic**: Designed with a deep midnight navy, slate, and electric cyan/teal palette tailored for strategic IT consulting and business advisory.
- **Strategic Ecosystem Architecture**: Clearly articulates the core differentiator: "Optimize before you create" and 3-5 year digital asset compounding.
- **The 5 Core Service Pillars**:
  1. Digital Growth & Search Visibility
  2. Online Reputation Management (ORM)
  3. Virtual Assistance & Business Support
  4. Business Development & Sales Support
  5. IT Consulting & Technology / AI Cost Optimization
- **Accepted Worldwide Payments**: Dedicated section highlighting Wise, PayPal, International Wire / Bank Transfer, and domestic UPI.
- **Client Engagement Frameworks**: Reusable, transparent case studies and draft editable activity templates (Leslie / Grace).
- **Interactive Tools**: Dynamic challenge selector / diagnostic tool, headline switcher, and an Opportunity Snapshot lead capture form.
- **Complete Technical SEO**: Semantic HTML5, Open Graph tags, Twitter cards, and Schema.org JSON-LD structured data.

## How to Deploy Live to GitHub Pages in 5 Minutes

### Step 1: Create a GitHub Repository
1. Log into your GitHub account at [https://github.com/](https://github.com/).
2. Click the **+** (plus) icon at the top right and select **New repository**.
3. Repository Name:
   - For a user site: name it `yourusername.github.io` (replace `yourusername` with your exact GitHub username).
   - For a project site: you can name it `mainitech` or `mainitech-website`.
4. Keep the repository **Public** (required for free GitHub Pages).
5. Click **Create repository**.

### Step 2: Upload the Files
1. On your new repository page, click **uploading an existing file** (or use Git CLI if you prefer).
2. Upload the following files and folders:
   - `index.html` (MUST be at the root of the repository)
   - `styles.css`
   - `script.js`
   - `assets/` folder (containing `logo.svg`)
   - `README.md`
3. In the commit message box, type `Initial release of MainiTech website` and click **Commit changes**.

### Step 3: Turn on GitHub Pages
1. In your repository, click the **Settings** tab (the gear icon near the top right).
2. On the left sidebar menu, click **Pages** (under the "Code and automation" section).
3. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`.
   - **Branch**: Select `main` (or `master`) and keep folder as `/ (root)`.
4. Click **Save**.
5. Wait 1 to 2 minutes. Refresh the page until GitHub displays:
   > *"Your site is live at https://yourusername.github.io/"* (or `/repository-name`).

### Step 4: Customization
- Replace email addresses (`contact@mainitech.com`) and WhatsApp phone numbers in `index.html` with your exact contact details.
- To connect a custom domain (e.g. `mainitech.com`), enter it under the **Custom domain** section in GitHub Pages settings and configure your DNS records.
